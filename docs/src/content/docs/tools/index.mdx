tirage has thirteen Tools, each named by its site slug. husk, vein, aura, benday, terrain, stitch, pith, mosh, mist and coral render a Still. sonar, kiosk and frond render a Loop, and frame 0 of a Loop is its Still. Each page shows a Still that tirage rendered, the command behind it, and the Parameters that `tirage tools` lists.
