tirage has 47 Tools, each named by its site slug. sonar, kiosk and frond render a Loop, and frame 0 of a Loop is its Still. Every other Tool renders a Still. Each page shows a Still that tirage rendered, the command behind it, and the Parameters that `tirage tools` lists.
