tirage has 51 Tools, each named by its site slug. Every Tool renders a Still and a Loop. Each Tool page shows both, the commands behind them, and the Parameters that `tirage tools` lists.

A Loop plays only while it is in view. With reduced motion on, it stays on its Still.
